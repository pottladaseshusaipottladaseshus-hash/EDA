# Exploratory Data Analysis (EDA)

## Objective
Analyze a small student dataset and discover simple patterns using Python, Pandas and Matplotlib.

## Files
- `students.csv` - input dataset
- `eda_analysis.py` - Python program
- `README.md` - project documentation

## Steps
1. Load the CSV using Pandas.
2. Display the first rows and summary statistics.
3. Calculate average marks by department.
4. Create a bar chart.

## How to Run
```bash
pip install pandas matplotlib
python eda_analysis.py
```

## Output
The program prints dataset details and creates `average_marks.png`.
